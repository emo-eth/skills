# emo-eth/skills

A library of explicit skills and instructions for coding agents.

## Plugins Cutover

Plugins have moved to a dedicated monorepo: [emo-eth/agent-plugins](https://github.com/emo-eth/agent-plugins).

All active plugins (e.g. `advisor-profiles`, `antigravity-prompt`, `bug-command`, `focus-order`, `grok-search`, `hard-update-restart`, `hyper-questions`, `local-model-router`, `model-invocable-skills`, `no-code-comments`, `pi-bots`, `plugin-updater`, `session-history`, `sidebar-descriptors`, `skiterate`, `tenet`, `ticket-bound-attention`, `wall-clock`, `yearn`) are maintained and tested in `emo-eth/agent-plugins`.
